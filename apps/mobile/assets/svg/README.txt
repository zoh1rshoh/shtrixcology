SHTRIXCOLOGY SVG starter assets
- logo-mark.svg: standalone S emblem
- wordmark.svg: editable vector text wordmark (uses system Arial/Helvetica; convert text to paths for exact typography)
- tagline.svg: standalone English tagline
- shtrixcology-animated-intro.svg: SVG with built-in SMIL animation; test in target browser/runtime before using in Expo.

Note: SVG files are editable starter vectors recreated from the logo concept, not a pixel-perfect trace of the generated raster logo. For native Expo animations, import separate SVG layers with react-native-svg and animate using the project's existing animation library. SVG SMIL animation support varies by renderer.
